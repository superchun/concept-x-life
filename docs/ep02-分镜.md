## 选题表

| 项 | 内容 |
|---|---|
| 编号和名字 | BUG-002 白熊效应 |
| 定义 | 越是刻意压抑某个想法，这个想法反而越频繁地浮现在脑海中。（丹尼尔·韦格纳，1987 年） |
| 困境 | 越不想想，越停不下来 |
| 悖论 | 你早就决定，不再想了。/ 所以，你想到了今天。 |
| 机制的结构 | 有一个不想要的念头或感觉；对自己下了一道「别」的命令；要执行命令就得不停检查「它来了没有」，检查本身把它叫回来 |
| 共同动作 | 告诉自己别做，结果更停不下来 |
| 世界 | 夜里的一间卧室，小人想睡觉，白熊从门口进来；门上的牌子「不许想白熊」；右上角一只铃，熊每来一次响一声；卧室是一栋楼里一百扇窗中的一扇 |
| 代价 | 照片、时间、睡意（守门花掉的）；请它进来时飘一次「安心 −1」 |
| 补丁 | 矛盾意向，弗兰克尔，1939 年，「别赶它。请它进来。」 |
| 状态变量 | 紧绷的程度，天色从深夜的冷色到天亮的暖色 |
| 仿真数字 | 旧规则 78 人睁眼到天亮，22 人睡着；新规则 87 人睡着，13 人没睡着 |
| 金句一 | 它一直回来，不是因为你放不下。/ 是因为你一直守着门。 |
| 金句二 | 放下，不是把它赶走。/ 是不再守着门。 |
| 结尾动作 | 想，就想吧。 |
| 最后一问 | 你的白熊，是什么？ |

出处核对的是二手资料（Simply Psychology、维基百科、ERIC 摘要），没有读论文原文。

## 六个症状

小动画统一成一个形状：按下去，弹回来，比原来更大。第二行字等「弹回来」那一下出现。

| 名字 | 第一行 | 第二行 | 小动画 |
|---|---|---|---|
| 一首歌 | 不想再哼了 | 又从头响了一遍 | 按下暂停键，音符从耳机里重新冒出来，更多 |
| 奶茶 | 说好今天不喝 | 满脑子都是 | 把杯子推出画面，弹回来变成三杯 |
| 上台 | 告诉自己别紧张 | 手开始抖 | 按住发抖的手，抖得更厉害 |
| 下班 | 说好不想工作 | 洗澡时还在想那封邮件 | 合上电脑，屏幕自己弹开，跳出邮件 |
| 失眠 | 告诉自己快睡 | 越躺越清醒 | 闭上眼，眼睛弹开，睁得更圆 |
| 和 TA | 说好不再想 | 又点开了头像 | 把手机扣在桌上，手机翻回来亮起头像 |
