# 第三期《一块钱的战争》：纯文字分镜（待确认）

2026-10-06 第二稿，全片约 106 秒。第一稿是像素场景（娃娃机、街道、小人），已废弃：画面改成以文字、结构和粒子为主，用 Remotion 做，不画角色和场景。视觉上延续前两期的像素风：像素字体、低分辨率画布放大、同一套调色板和辉光。

概念：美元拍卖（Dollar Auction）。马丁·舒比克，1971 年，《冲突解决杂志》第 15 卷第 1 期。

写的时候做了这些假设，都还没定：

- 竖屏，画布 270×480 放大 4 倍到 1080×1920。大字和柱子在竖屏里能占满手机，横屏也能排，但字会小一半。
- 「字」这一列按屏幕文字写，改成人声也能用。
- 硬币是发光的像素方块，柱子是硬币一格一格码起来的，按钮是街机按钮的样子。每个场景的线旁边可以放一个十几像素的小图标（娃娃、公交、手柄、手机），只当标签用，不做动画。

## 全片只用三样东西

| 画面元素 | 代表 | 样子 |
|---|---|---|
| 一条线 | 这东西值多少 | 横贯画面的细线，左端写着数 |
| 一根柱子 | 已经付出的 | 硬币粒子一颗颗落下堆成，超过线的部分变成橙色 |
| 一个按钮 | 再加一点 | 屏幕底部的圆角按钮，一直在轻轻跳，上面的数永远很小 |

抓娃娃、拍卖、等车、打游戏、冷战，都用这三样来演，只换上面的字。观众看到第三个场景时，不用解释就认得出这是同一件事。

## 分镜

| 时间 | 画面 | 字 |
|---|---|---|
| 0–2 秒 | 第 0 帧：一根发光的硬币柱已经堆得很高，上半截是橙色的，一颗硬币正落下来砸在柱顶，溅起几粒光点。柱子腰部横着一条线，左端写「娃娃 10 块」。底部按钮「再抓一次 1 块」在跳 | 这个娃娃，卖十块。 |
| 2–5 秒 | 又一颗硬币落下。柱子旁的大数字从 22 翻到 23，橙色那一截闪了一下 | 他已经投了二十三块。 |
| 5–8 秒 | 柱子缩到画面一侧继续落币，标题逐字打在中央 | 一块钱的战争 |
| 8–11 秒 | 柱子的硬币从上往下一颗颗飞回屏幕上方，数字倒着翻回 0。只剩线和按钮。落下第一颗 | 第一块：试一下。 |
| 11–14 秒 | 落到第五颗。画面中央弹出两个字「差一点」，抖了一下散成粒子 | 第五块：就差一点。 |
| 14–19 秒 | 落到第十颗，柱顶正好碰到线，线亮了一下。画面停半秒，按钮不跳了，然后又开始跳 | 第十块：现在走，这十块就白花了。 |
| 19–23 秒 | 第十一颗落下，越过线，变成橙色。之后越落越快，11、12、13 | 再一块。就一块。 |
| 23–30 秒 | 柱子冲到 23。其他东西淡出，只剩两个数上下并排：很大的「已投 23」，很小的「再投 1」 | 每一次，他比的都是这两个数。 |
| 30–35 秒 | 「再投 1」那颗硬币落下，镜头跟着它，硬币越来越大，停在画面中央，变成一枚大硬币，面上写着「1 块」 | （无字） |
| 35–40 秒 | 大硬币缩到画面上方。它下面拉出一条线，左端写「1 块」。线下方左右各出现一个空的柱位 | 1971 年，一位经济学家拿一块钱出来拍卖。 |
| 40–45 秒 | 两条规则一条一条打出来。第二条出现时，两个柱位各闪一下 | 出价最高的人，拿走这一块钱。出价第二的人，也要照价付钱。 |
| 45–48 秒 | 画面停一拍，大硬币慢慢转。底部并排三个选项：五毛、一块、三块 | 你猜，这一块钱最后卖了多少？ |
| 48–53 秒 | 左右两根柱子轮流长高，硬币粒子从两侧飞入，柱顶的数字快速跳：五分、一毛、两毛……直到左九毛、右八毛，都还在线下面。音效逐级升调 | （无字） |
| 53–59 秒 | 放慢。右柱旁展开两行小字：「停手：亏八毛」「出一块：不亏」。第二行亮起，右柱长到正好碰线 | 出八毛的人算了一下。 |
| 59–65 秒 | 左柱旁展开两行：「停手：亏九毛」「出一块一：亏一毛」。第二行亮起，左柱越过线，冒出一小截橙色。上方的大硬币暗了一下 | 出九毛的人也算了一下。于是有人出一块一，买一块钱。 |
| 65–70 秒 | 两根柱子交替往上冲，粒子流越来越密，全是橙色。镜头不得不一直拉远，那条「1 块」的线一路沉到画面最底下，变得很细 | 从这一步起，没有人是为了赢。 |
| 70–76 秒 | 停住。两根高柱，底下一条细线。两个柱顶的数字相加，合成一个大数。角落小字：Dollar Auction，Martin Shubik，1971 | 这样的拍卖，两个人加起来付出三到五块，并不少见。它叫美元拍卖。 |
| 76–80 秒 | 柱子、线、按钮各自亮一下，旁边依次标出：「已经付出的」「它值多少」「再加一点」。然后三样东西清空，等下一组字 | （无字） |
| 80–87 秒 | 线的字换成「走路回家 20 分钟」，柱子标「已等 25 分钟」，已经越线。按钮「再等 1 分钟」在跳。一个小光点慢慢靠近按钮，没碰到，画面就换了 | （无字） |
| 87–92 秒 | 线：「本来只玩 2 把」。柱子：「连输 6 把」。按钮：「再来一把」。光点靠近，换走。比上一个快 | （无字） |
| 92–96 秒 | 线：「一句对不起」。左右两根柱子并排，各标「第 5 天」。按钮：「再等一天」。按钮上方闪过一行「对方正在输入…」，又消失了。换走 | （无字） |
| 96–102 秒 | 回到娃娃那一组。柱子 31。最后一颗硬币落下，全屏炸开一圈彩色粒子，中央弹出大字「抓到了」 | （无字） |
| 102–106 秒 | 粒子落尽。只剩两个数并排：「娃娃 10」「已投 31」。标题在下方再出现一次 | 他赢了。 |

全片字幕 18 句。80 秒之后没有字幕，只有三样东西上面的标签。

## 对照手册

- 前 2 秒：第 0 帧是亮的硬币柱和正在落下的硬币；第一句单独成立；到第 5 秒观众知道他花 23 块抓一个 10 块的娃娃。
- 日常：五个场景都是人人经历过的，用线、柱子、按钮上的字来讲。
- 讲清概念：两条规则、关键的两步计算、名字和出处都上屏。
- 不引导：没有建议，没有「这就是你」；后三个场景只演到按钮被按下之前；结尾只陈述画面。
- 连续：全片是同一组三样东西，靠镜头跟随硬币和拉远连接。

## 需要你确认的

1. 画面只用线、柱子、按钮和硬币粒子（像素风），这个方向对不对；场景旁边要不要加小图标。
2. 竖屏还是横屏；字幕还是人声。
3. 45–48 秒「你猜卖了多少」留不留。
4. 结尾「他赢了」是否合适。
5. 后三个场景（等车、游戏连输、冷战）换不换。

## 事实核对

- 已核对：论文题目、作者、期刊、年份（Shubik, M. 1971. The Dollar Auction Game: A Paradox in Noncooperative Behavior and Escalation. Journal of Conflict Resolution, 15(1), 109–111）；两条规则；出价以五分为单位。
- 「两个人加起来付出三到五块并不少见」出自转引的论文原句（a total of payments between three and five dollars is not uncommon），来源是二手文章，论文原文没有读到。
- 一块一之后的具体叫价、娃娃机的 10 块和 31 块、后三个场景里的数，都是为画面设计的示例。
- 原实验用的是美元，片中说成「一块钱」，角落小字保留英文名和出处。
