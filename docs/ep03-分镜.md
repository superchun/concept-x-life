# 第三期《一块钱的战争》：纯文字分镜（待确认）

2026-10-06 第一稿。全片约 106 秒。

概念：美元拍卖（Dollar Auction）。马丁·舒比克，1971 年，《冲突解决杂志》第 15 卷第 1 期。

写的时候做了这些假设，都还没定：

- 「字」这一列可以是屏幕文字，也可以是人声，写法两边都能用。
- 画面按一个连续的像素场景写，横屏竖屏都能排。
- 日常场景选了抓娃娃机，理由和备选见文末。

## 一条线

一个人在抓娃娃，投的币早就超过了娃娃的价钱 → 倒回去看每一个币是怎么投下去的 → 镜头跟着硬币进到机器里，里面是 1971 年那场拍卖，规则跑一遍 → 拍卖里的三个标注回到街上，自己贴到别的场景上 → 回到娃娃机，他抓到了。

| 2–5 秒 | 小人又投进一个币，投币口上方的计数从 22 跳到 23。爪子再次移动 | 这是他投的第二十三个币。 |
| 5–8 秒 | 爪子下落、滑掉。标题叠在画面上打出，机器的灯继续闪 | 一块钱的战争 |
| 8–11 秒 | 计数快速倒转回 0，娃娃机回到他刚走过来的样子。投第 1 个币，计数「已投 1」 | 第一个币：试一下。 |
| 11–14 秒 | 爪子抓起娃娃，到出口边掉了。计数跳到 5 | 第五个：就差一点。 |
| 14–19 秒 | 计数到 10，和价签「10」并排亮了一下。小人转身走了半步，停住，回头。计数旁边多出一行「再投 1」 | 第十个：已经花了十块。现在走，这十块就白花了。 |
| 19–23 秒 | 他走回来投币。之后每投一次，「已投」加一，「再投」永远是 1。节奏加快，11、12、13 连着跳 | 再投一块，就一块。 |
| 23–30 秒 | 计数一路跳到 23，回到开场那一刻。画面上只剩两个数并排：「已投 23」「再投 1」。他的手停在投币口 | 每一次，他比的都是这两个数。 |
| 30–35 秒 | 他把币投进去。镜头跟着这枚硬币钻进投币口，沿着轨道往下滚 | （无字） |
| 35–40 秒 | 硬币滚到一张小桌子中央停下。机器内部是一个小房间，桌子两边各站一个小人，头顶举着牌子，上面是空的 | 1971 年，一位经济学家拿一块钱出来拍卖。 |
| 40–45 秒 | 两条规则依次出现在桌子上方。第二条出现时，右边小人头顶的牌子闪了一下 | 出价最高的人，拿走这一块钱。出价第二的人，也要照价付钱。 |
| 45–48 秒 | 画面停一拍，硬币在桌上转。底部出现三个选项：五毛、一块、三块 | 你猜，这一块钱最后卖了多少？ |
| 48–53 秒 | 两人轮流举牌，数字快速往上跳：五分、一毛、两毛……一路到左边九毛、右边八毛。音效逐级升调 | （无字） |
| 53–59 秒 | 放慢。右边小人（八毛）头顶展开两行：「停手：亏八毛」「出一块：不亏」。他举牌：一块 | 出八毛的人算了一下。 |
| 59–65 秒 | 左边小人（九毛）头顶展开两行：「停手：亏九毛」「出一块一：亏一毛」。他举牌：一块一。牌子上的数字第一次超过桌上的硬币，硬币暗了一下 | 出九毛的人也算了一下。有人出一块一，买一块钱。 |
| 65–70 秒 | 两人头顶的两行字不断刷新，「停手」那一行的数字越来越大，「再加」那一行永远只多一毛。举牌越来越快：一块五、两块、两块六 | 从这一步起，没有人是为了赢。 |
| 70–76 秒 | 举牌停住。两块牌子并排，下面打出合计。镜头缓缓拉远，桌上的硬币还是那一枚。角落小字：美元拍卖，Martin Shubik，1971 | 这样的拍卖，两个人加起来付出三到五块，并不少见。它叫美元拍卖。 |
| 76–80 秒 | 两人头顶的三个标注留在画面上：「已经付出的」「再加一点」「停手就全亏」。镜头往上退出机器，回到娃娃机前，再继续拉远到整条街 | （无字） |
| 80–87 秒 | 镜头沿街平移到公交站。一个人在等车，旁边停着一辆出租车。三个标注自己飘过来贴上：「已等 25 分钟」「再等 1 分钟」。他看了一眼出租车，又看了一眼表。镜头没等他决定就移走了 | （无字） |
| 87–92 秒 | 一扇窗里，一个人对着屏幕，屏幕上是「失败」。标注贴上：「连输 6 把」「再来 1 把」。他的手指悬在按钮上。镜头移走 | （无字） |
| 92–96 秒 | 另一扇窗里，两个人背对背，各自的手机扣在桌上。标注贴上：「第 5 天」「再等 1 天」。镜头移走，比上一个更快 | （无字） |
| 96–102 秒 | 镜头回到娃娃机。计数「已投 31」。爪子落下，抓稳，娃娃掉进出口。机器的灯全亮，响起中奖音乐。他把娃娃抱起来 | （无字） |
| 102–106 秒 | 他抱着娃娃站着。头顶并排两个数：「娃娃 10」「已投 31」。娃娃机的灯还在闪。标题再出现一次 | 他赢了。 |

全片的字一共 18 句。80 秒之后只有画面里的标注，没有字幕。

## 对照手册

- 前 2 秒：第 0 帧是亮的娃娃机和正在下落的爪子；第一句单独成立；到第 5 秒观众知道他花 23 块抓一个 10 块的娃娃。
- 不引导：没有建议，没有「这就是你」。80 秒之后三个场景都只演开头，结局不演。结尾「他赢了」只陈述画面。
- 讲清概念：规则两条、关键的两步计算、名字和出处都上了屏。
- 连续场景：娃娃机、机器内部、街道是同一个镜头，靠跟随硬币和拉远连接，没有换版式。

## 需要你确认的

1. 第一个场景用抓娃娃机，备选是等公交、情侣冷战。选娃娃机是因为它本身就按「一块钱一次」计数，和标题对得上，画面亮，结果能数清。它是一个人对机器，拍卖是两个人对抗，对应的是「已经付出的、再加一点、停手就全亏」这三样，不是对手。
2. 45–48 秒那句「你猜卖了多少」留不留。它问的是规则，不涉及观众的生活。
3. 结尾「他赢了」是否合适，或者最后一句也不要。
4. 87–96 秒的两个场景（游戏连输、冷战）换不换。

## 事实核对

- 已核对：论文题目、作者、期刊、年份（Shubik, M. 1971. The Dollar Auction Game: A Paradox in Noncooperative Behavior and Escalation. Journal of Conflict Resolution, 15(1), 109–111）；两条规则；出价以五分为单位。
- 「两个人加起来付出三到五块并不少见」出自转引的论文原句（a total of payments between three and five dollars is not uncommon），来源是二手文章，论文原文没有读到。
- 片中九毛对八毛之后的具体叫价（一块五、两块、两块六）是为画面设计的示例。
- 原实验用的是美元，片中说成「一块钱」，角落小字保留英文名和出处。
