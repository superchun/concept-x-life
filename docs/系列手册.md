# 《人生 bug 图鉴》系列手册

做新一期时照这份手册走：先过第 2 节的六关，填第 3 节的选题表，按第 4 节排分镜，画面和文案的做法在第 5、6 节，代码怎么复用在第 9 节。

已有两期可以当范例，它们代表两种类型：

- 第一期 BUG-001 局部最优是**算法型**：困境是「不肯动」，概念可以写成能跑的规则，前后两种规则有数字对比。
- 第二期 BUG-002 白熊效应是**心理型**：困境是「一直在用力」，概念来自一个实验，没有可比的数字，靠事实和情绪推进。完整分镜在 `docs/ep02-分镜.md`。

新概念先判断更接近哪一种，下面凡是两期做法不同的地方都分开写了。

两期成片用的是旧结构：五段按固定顺序排，症状做成六张卡片，定义和金句各自压暗成卡，顶部有进度条。发布后的数据（第 13 节）显示第二期的开场留不住人，两期在 5 秒之后都低于同类作品。从第三期起改成第 4 节的做法：五样内容只是清单，全片是一个连续的世界。这套做法还没有成片验证，第三期发布后按数据回来修订。两期的选题、文案、世界和补丁仍然可以当范例，结构和版式不要照搬。

## 1. 系列公式

**一个有名字的机制，解释一种人人都有的困境，用一个像素世界演出来。**

机制不限学科：计算机、数学、心理学、经济学都可以，冷门的也可以。首要标准是日常，症状要一说就中。

每期由四样东西组成，缺一样就不成立：

| 组成 | 说明 | 第一期 | 第二期 |
|---|---|---|---|
| 困境 | 观众已经在经历、但说不清原因的事 | 明明不满意，却一直不动 | 越不想想，越停不下来 |
| 概念 | 一个有名字、有出处的机制，结构和困境相同 | 局部最优 | 白熊效应 |
| 世界 | 把机制做成一个像素场景，主角就是「你」 | 小人爬山，只能往上走 | 夜里的卧室，白熊在门外 |
| 补丁 | 这个机制已有的解法，翻译成一句人话 | 模拟退火：偶尔允许走一步下坡 | 矛盾意向：别赶它，请它进来 |

固定的形式：16:9 横屏，无人声，屏幕文字加音乐，全像素游戏风，100 到 110 秒。

## 2. 概念怎么选

一个概念要同时过这六关。前五关必须过，第六关只对算法型有要求。

1. **够日常。** 症状里多数是观众当天就可能遇到的小事。先过这一关再看别的：第二期选题时，最优停止和上下文切换都是因为不够日常被否掉的。
2. **机制反直觉。** 能写成「因为 A，所以反而 B」的悖论。（每一步都选更好，所以被困住。告诉自己别想，所以一直在想。）
3. **和困境同构。** 困境里的每个要素在概念里都有对应物，不是比喻沾边。检验办法：把日常例子逐条对到机制的三条成立条件上，对不上说明概念选错了或例子选错了。
4. **能做成世界。** 可以画成小人在规则下行动的画面，并且规则能写成一块牌子。
5. **有补丁。** 有一个有名字、有出处的解法，改的是规则本身，不是「要努力」。没有能翻牌的新规则，片子后半段撑不起来；杰文斯悖论、古德哈特定律、享乐适应都卡在这一关。
6. **有数字或事实。** 算法型要能写一个小仿真，改规则前后有明显对比。其他类型不要自己造数字，用真实实验里的事实（「五分钟内，铃每分钟都在响」）。

## 3. 选题表

开工前填完这张表。填不出来的格子就是还没想清楚的地方，不要开始做画面。

| 项 | 要求 | 第一期 | 第二期 |
|---|---|---|---|
| 编号和名字 | BUG-00X + 概念名 | BUG-001 局部最优 | BUG-002 白熊效应 |
| 定义 | 一句完整的词条，上屏用 | （第一期没有） | 越是刻意压抑某个想法，这个想法反而越频繁地浮现在脑海中。 |
| 困境 | 一句话，不带术语 | 不满意，却一直不动 | 越不想想，越停不下来 |
| 悖论（开头两句） | 第二句推翻第一句；第一句带上时间的分量，单独读也成立；两句 3 秒内说完 | 这十年，你每一步都选了更好的。/ 所以，你被困住了。 | 你早就决定，不再想了。/ 所以，你想到了今天。 |
| 机制的结构 | 列出 3 条成立条件 | 现状是一步步选出来的，不差；往旁边动一下会先变差；知道有更好的可能 | 有一个不想要的念头；对自己下了「别」的命令；执行命令要不停检查，检查把它叫回来 |
| 共同动作 | 所有症状共有的一个动作 | 试了新的，不如原来的，又退回去 | 告诉自己别做，结果更停不下来 |
| 症状 | 三到六个，见第 6.2 节 | 奶茶、理发、游戏、学习、工作、和 TA | 一首歌、奶茶、上台、失眠、下班、和 TA |
| 世界 | 场景、主角、规则牌上的字 | 六座山；小人；「只能往上走」 | 卧室和整栋楼；床上的小人和门外的白熊；「不许想白熊」 |
| 代价 | 三个词，见第 5.5 节 | 分数、效率、体面 | 照片、时间、睡意 |
| 补丁 | 名字、出处年份、一句人话 | 模拟退火，1983 年，「偶尔，允许自己走一步下坡」 | 矛盾意向，1939 年，「别赶它。请它进来。」 |
| 状态变量 | 一个随剧情变化、能用天色表现的量 | 温度 | 紧绷的程度，深夜到天亮 |
| 数字或事实 | 算法型填仿真数字；其他填真实的事实 | 27 → 94，还有 6 个没到 | 实验：五分钟，想到就按铃，每分钟都在响 |
| 金句一（诊断） | 否定观众的自责 | 困住你的不是懒，是你太会选「更好」。 | 它一直回来，不是因为你放不下。是因为你一直守着门。 |
| 金句二（结论） | 全片要被截图的那句 | 只肯往上走的人，到不了最高的地方。 | 放下，不是把它赶走。是不再守着门。 |
| 结尾动作 | 能从金句二直接推出来，并回答开头第一句 | 下一步，不必更好。 | 想，就想吧。 |
| 最后一问 | 一句话就能在评论区回答 | 困住你的山，是什么？ | 你的白熊，是什么？ |

出处的年份和人名要查证后再填。

## 4. 结构：五样内容，一个连续的世界

一期片子要讲到下面五样。它们是核对内容用的清单，不是时间顺序，也不出现在屏幕上。先后、各占多长、用什么画面讲，每期按概念自己定：比如代价可以并进困境里演，命名可以放到机制演完之后。

| 内容 | 观众看完这一部分应该知道 |
|---|---|
| 困境 | 这说的是我 |
| 机制 | 为什么会这样，它有名字 |
| 代价 | 照现在这样下去要付出什么 |
| 补丁 | 规则可以怎么改，今晚能做什么 |
| 落点 | 一句带得走的话，和一个留给自己的问题 |

排的时候守住这几条：

- 第 0 帧就在世界里。全片是同一个连续的场景，只靠镜头推、拉、平移，不换版式，不用卡片，不用转场。
- 读字的时候画面不停。概念名、定义、金句都叠在世界上，后面的画面继续动，见第 5.3、5.9 节。
- 节奏有快有慢，不按固定时长分配。症状要快，一个一两秒；揭示机制和补丁落地的地方放慢。连续三句以上用了同样的时长，就检查是不是排得太匀。
- 一句字幕配一个画面上的变化。全片屏幕文字 20 句上下，没有字的时间留给画面和音乐。
- 翻牌、高潮、金句二的秒数定下来后告诉做音乐的人，见第 8 节。

分镜逐段写，四列：时间（秒）、画面、屏幕文字、讲的是清单里的哪一样。最后一列只用来核对五样有没有讲全。`docs/ep02-分镜.md` 是旧结构的分镜，写画面和文字的细致程度可以参考。

两期成片是按固定五段、每小节 3 秒排的，留在这里对照：

| 段落 | 要完成的事 | 第一期（34 小节） | 第二期（37 小节） |
|---|---|---|---|
| 症状 | 开场演悖论；六个症状；命名 | 0–7 | 0–7 |
| 根因 | 讲清概念；进入世界；金句一 | 8–14：爬到山顶，拉远看到更高处 | 8–16：词条卡，实验，卧室里出现守门人，推近看画像 |
| 代价 | 见第 5.5 节 | 15–18：试着下山，失去三样，退回；一百个人多数停在原地 | 17–21：删掉、盖住、骂自己；撑不住；全回来了；整栋楼都亮着 |
| 补丁 | 规则牌翻面；主角按新规则走一遍；推广到所有人 | 19–26：翻牌，退火，一百人重跑，烟花 | 22–29：翻牌，熊进来坐下，主角睡着，另外三扇窗 |
| 结论 | 高潮收尾；金句二；回到开场做相反的动作；最后一问 | 27–33 | 30–36：熄灯天亮，金句二，不再拍掉气泡，最后一问 |

## 5. 表现手法

5.4 到 5.8、5.11、5.13 是两期做过并且能用的做法。5.1 到 5.3、5.9、5.10 按第二期的数据改过，第三期第一次用。

### 5.1 开场：前 2 秒

第二期有一半以上的人在 2 秒内划走。两期的开场并排看，区别很具体：第一期从第 0 帧起小人就在爬台阶，镜头跟着上移，年份半秒跳一次，第一句「这十年，你每一步都选了更好的」单独读就成立；第二期镜头不动，小人躺着，第 0 帧没有字，悖论的后半句 4 秒才出现。

开场要同时满足：

- 第 0 帧就有亮的主体在动，不是一张暗的空场景。
- 第一句字幕 0.5 秒内出现，单独读就是一句完整的话，带上具体的量或对象。
- 悖论两句在 3 秒内说完。
- 前 6 秒里镜头或主角每秒都有位移。
- 开场就是世界本身，后面直接接着演，不切走。

内容仍然是把「因为 A 所以 B」演成一个动作，结尾主角卡住。第一期：十级台阶，一年一级，走到顶，左右都是「更差」。第二期：拍掉一个气泡，冒出两个；再拍，四个。这个动作在片尾还要用一次，设计时就留好「相反动作」的余地。

开场最先做，做完单独检查，见第 11 节。

### 5.2 症状放进世界里

症状是世界里正在发生的事，镜头扫过去，不单独做成卡片。数量三到六个，够让观众认出自己就行。

- 每个症状是场景里的一个人或一样东西在做共同动作，形状要一致（第一期：伸出去、缩回来；第二期：按下去、弹回来、更大）。
- 文字贴在它旁边：名字用黄色，加一行字，等动作发生的那一下才出现。
- 一个一两秒，镜头不停。
- 蓝色小虫留在画面角落计数，每过一个症状多一只。

第二期如果按这个做法，症状可以是楼里的几扇窗，每扇窗里的人做同一个动作。

### 5.3 命名和定义

小虫合成一只大虫，打出「BUG-00X」和概念名。这一下叠在世界上发生，不白闪，不换底，1.5 秒内完成。

定义仍然要完整上屏，只讲故事或只演成画面不算把概念解释清楚。但不再停下来逐字打一整段：拆成两三句字幕，每句配世界里的一个动作，出处用一行小字带过。

概念出自实验时，实验也在世界里演（第二期的铃本来就挂在卧室里），不另起一个版式。只用查证过的事实。

### 5.4 概念做成一个连续的世界

一个连续的场景，主角就是观众。规则写在一块牌子上。从第 0 帧起就在这个场景里，全靠镜头推近和拉远。第二期的卧室和整栋楼用同一套镜头坐标，卧室是楼里的一扇窗，拉远就是整栋楼。

机制只讲一层。第二期最初用了两个帮手，一个找别的事想，一个守门，对应心理学里的两个过程；成片里观众分不清谁是谁，后来只留了守门人。判断标准：一句话加一个画面讲不完的解释，就是多出来的那一层。

概念里的东西要变成每个人自己的。第一期把奶茶店、工位、沙发搬上了山顶；第二期让白熊在出场时先变成一个音符、一句话、一个头像，守门人手里的画像也在这几样之间翻动。这样最后一问才有着落。

### 5.5 代价

主角头顶飘出「某某 −1」，橙色，三次。不解释，观众自己懂。

这一段演什么，取决于观众的问题出在哪：

- 观众是不肯改变（第一期）：演改变要付出什么。主角试一下，失去三样东西，退回原地。
- 观众是一直在用力（第二期）：演现在的做法要付出什么，再演撑不住之后的反弹。动作要取自真实生活（删聊天记录、刷手机、骂自己），不要从概念里推（加锁、加守门人）。

两种情况下，改变本身的代价都要在补丁段出现一次（第二期：熊走进来时飘出「安心 −1」，他没有推）。

### 5.6 从一个人到所有人

先讲主角一个人，再让观众看到所有人都一样。这一步把「你的问题」变成「机制的问题」。

- 算法型：放出一百个小人按同一规则跑，屏幕上出现统计数字，改规则后重跑对比。
- 其他类型：不用数字。第二期是镜头拉远，整栋楼每扇窗都亮着（「不只是你」）；补丁之后镜头经过另外三扇窗，每扇窗里的人各说一句允许自己的话，说完灭一盏灯，然后整栋楼熄灯。

### 5.7 补丁是翻牌

规则牌移到画面中央，翻面，换成新规则。同时状态变量开始变化，天色从冷变暖。然后主角按新规则走一遍。

高潮的样子跟着概念走：第一期是登顶、烟花、画面轻震；第二期是熄灯和天亮，安静的。高潮用的画面语言最好和开场一致（第二期开场是气泡越拍越多，反弹时气泡铺满屋子，补丁之后气泡散掉）。

### 5.8 后半段不回头

翻牌之后情绪要一直往下走，不回头做补充说明、免责或对结果的保证。第二期删掉了「这不是保证」「也有几扇亮到了天亮」这类句子。

只有用了统计数字的片子（第一期），才需要交代没成功的那部分，让数字可信。

补丁要落到今晚就能做的事。「请它进来」之后要有具体的句子：「睡不着，就先醒着。」「手要抖，就让它抖。」

### 5.9 金句

全片只有两句：一句诊断，一句结论。120 像素大字居中，叠在世界上；画面可以压暗一些，但镜头继续缓慢移动，不停成一张卡。字出完停到能读完为止，不固定占多长。写法见第 6.3 节。

### 5.10 回到开场，做相反的动作

片尾镜头回到 5.1 的位置，途中再经过那几个症状，不切成闪回。然后主角做出开场没做的那个动作，代价照样飘出来，但这次没有退回。镜头拉远，露出开场镜头里看不到的东西（第一期是更高的台阶，第二期是每扇窗里都有一个气泡）。

### 5.11 最后一问

最后一帧是一个问题，画面继续轻微运动，底部一行小字写系列名和编号。问题要让人一句话就能答，而且答案是关于自己的。

### 5.12 贯穿全片的元素

- 屏幕上不放进度条，也不出现段落名。
- 蓝色小虫：系列的标志，出现在症状计数、命名、封面。
- 主角：黄色的像素小人，第一期戴帽子，第二期在床上戴睡帽。全景里不小于 20 像素高（按 480×270 的画布算），会眨眼。
- 新角色先出定妆图确认造型，再做动画。场景里的东西按同一个像素倍数画，人、家具、动物的比例要对得上。

### 5.13 字和画说同一件事

每一句字幕，画面上都要有对应的东西在发生。第二期有一句字幕在讲实验（「禁令解除后」），画面却是卧室里熊涌进来，观众看不懂，后来改成了只描述画面的「一松手，它全回来了」。

同一时间屏幕上要看的东西不超过两三样。一样东西用完就收掉。

## 6. 文案

### 6.1 通用规则

- 书面语，不用语气词和网络口语。
- 术语只有概念名和补丁名。概念名在命名和定义里出现，补丁名出现一次。
- 一句话一个意思，重点词用颜色标出：问题用蓝色，解法用绿色。
- 数字只用两种：仿真跑出来的（直接引用变量，不手写），或查证过的事实。不为了显得有说服力去造数字。
- 首尾一问一答：结尾动作那句要能回答开头第一句。
- 结尾动作必须由金句二推出。找不到同时「够轻」又「符合逻辑」的具体例子时，不举例，让主角用动作完成。
- 陈述画面上发生的事，不解释、不保证。「它还在。你也睡了。」好过「它也许还在。只是它在，你也能睡了。」

### 6.2 症状

三到六个。两条要求同时满足：

- **对得上机制。** 逐条核对选题表里的三条成立条件。只是「习惯」或「懒」的例子不要。
- **是一个真实的瞬间。** 写具体场景里发生的一个动作，不写概括。从概念推出来的「标准案例」没有共鸣：第二期的「下班」最初是「洗澡时还在想那封邮件」，换成「洗澡时又想起领导的一句话」之后才扎心。

写法：`场景｜做了什么，结果怎样`，结果那半句就是共同动作。贴在画面里的那一行最多 13 个字。

- 奶茶｜新品看了五分钟，还是点了老样子
- 失眠｜告诉自己快睡，越躺越清醒

配置：学生、工作、生活都要有；从轻到重排，最扎心的放最后；素材优先用自己和身边人真发生过的事。

### 6.3 金句和句式

金句要回应观众为什么自责，不是把道理说得巧。先问：观众会用哪个词骂自己（懒、放不下、没出息）。金句一否定这个词，金句二给出路。

- 第二期最初的金句一是「不是你意志力差。是『别想』本身，就在想。」，像绕口令，而且没人会用「意志力差」来骂自己想一个人。改成了「它一直回来，不是因为你放不下。是因为你一直守着门。」
- 两句金句最好共用一个片子里演过的画面（守着门、不再守着门），前一句是诊断，后一句是出路。
- 金句二要能离开画面单独成立，观众可以拿来对自己说。

常用句式：

| 位置 | 句式 | 第一期 | 第二期 |
|---|---|---|---|
| 命名前 | 这些是同一件事。 | 同 | 同 |
| 进入世界 | 把症状对到世界上 | 更熟的题。更快的方法。更不费力的关系。 | 你的白熊，可能是一首歌，一句话，一个人。 |
| 揭示 | 一句话点出机制 | 你站在山顶。只是这座山不高。 | 守门的人，得一直记着它的样子。 |
| 金句一 | 【它】不是因为【自责的理由】，是因为【机制】。 | 困住你的不是懒，是你太会选「更好」。 | 它一直回来，不是因为你放不下。是因为你一直守着门。 |
| 认可 | 这很合理。 | 同 | 想把它赶走，这很合理。 |
| 出处 | 【年份】年，有人【做了相反的事】。 | 1983 年，有人改了这条规则。 | 早在 1939 年，一位医生就开过相反的处方。 |
| 补丁 | 【新规则的人话】。它叫【名字】。 | 偶尔，允许自己走一步下坡。它叫模拟退火。 | 别赶它。请它进来。它叫矛盾意向。 |
| 落到今晚 | 【症状】，就【允许】。 | （没有） | 睡不着，就先醒着。 |
| 金句二 | 重新定义一个观众熟悉的词，或「只【做 A】的人，【得不到 B】」 | 只肯往上走的人，到不了最高的地方。 | 放下，不是把它赶走。是不再守着门。 |
| 结尾动作 | 回答开头第一句 | 下一步，不必更好。 | 想，就想吧。 |

只有算法型才用的三句：统计（一百个小人，73 个停在小山上）、对比（27，变成 94）、诚实（还有 6 个没到。这不是保证，只是机会）。

## 7. 视觉规范

- 画布 480×270，放大 4 倍到 1920×1080，最近邻缩放。
- 调色板 Sweetie 16（`src/lib/theme.ts` 的 `P`）。问题、小虫用蓝；解法、亮起的路用绿和黄；代价用橙；失败用红。
- 字体 Fusion Pixel 12px，字号只用 12 的倍数：正文 60，症状名 96，金句 120。需要一字一字读完的长句（词条定义）用 72。
- 镜头的放大倍数用整数（1、2、3），非整数会让像素大小不均。拉远、推近的过程中短暂经过非整数倍可以接受。
- 辉光：整帧复制一层，模糊后以滤色叠加。亮色像素会发光。
- 天空是五条横向色带，在冷色和暖色之间按状态变量混合。
- 所有随机数带种子，每一帧只依赖帧号。
- 字幕在画面下方居中，带描边，下面垫一条深色渐变。画面里的东西不要放到字幕那一条上。
- 全片不用转场，画面的变化都靠镜头移动。
- 不用 emoji；不用像现成品牌吉祥物的形象；不做「深色底大字加粒子流」的版式。

## 8. 声音

- 音乐由人单独生成、挑选和剪辑，不由代码这边合成。分镜确认后，把画面上要对齐的时间点交给做音乐的人：规则牌移到中央（音乐安静的一段）、翻牌（进入最响段落的那一下）、高潮、金句二、结束。
- 音乐可以沿用上一期的，同一首反复出现是系列的标志。第一、二期用的是 Mountain Ascent 和 Quiet Courage 叠加。
- 音乐的方向：暖、厚、低频足；从第一秒就有内容；用钢琴或贝斯的八分音符推动，鼓要少；主旋律能哼；情绪是「好奇、探索、下定决心」，不催泪，不滑稽。全曲只在翻牌前抽空一次。
- 代码里的一小节（`BAR`，3 秒）只是写时间表用的单位，一件事不必正好占一小节；它也不是音乐的小节（那两首约 110 拍每分钟，一小节约 2.18 秒）。画面只在翻牌、高潮、金句这几个大的位置和音乐对齐。
- 音效用 `scripts/sfx.ts` 合成，挂在每期 `sfx.ts` 的时间表上。固定用法：上升的动作逐级升调，下降逐级降调；症状出现一声；命名和金句各一声重音；镜头拉远一声低音；代价一声钝响；翻牌一声。高潮的音效跟着画面走，安静的高潮不用号角和烟花。

## 9. 代码怎么复用

目录：

- `src/lib/`：整个系列通用。画布、文字、字幕、转场、数学工具、调色板。不用改。
- `src/ep01/world.ts`：天空、主角、小虫、气泡、烟花等通用画法，加上第一期的地形和道具。之后各期从这里引用通用部分，不复制。
- `src/ep02/` 是最近的一期，新一期以它为起点：
  - `Ep02.tsx`：总装。各段、字幕、音效和音乐拼成一条时间线，音乐文件名（`BGM`）和音效开关（`SFX_ON`）在文件顶部。里面的进度条（`Progress`）和像素块转场（`PixelWipe`、`CUTS`）是旧结构的，新一期删掉。
  - `script.ts`：总时长、各段起点、症状、全部屏幕文字。新一期先改这个文件；`STAGES` 是给进度条用的，一起删掉。
  - `world.ts`：这一期新增的角色和道具，用字符图画像素角色的 `sprite`。
  - `symptoms.tsx`：旧结构的症状卡、命名和词条卡、闪回。新一期不用这套版式，只把里面小动画的画法搬进世界那个文件。
  - `room.tsx`：开场、概念卡、连续的世界。每期重写，新一期的开场、症状、命名都并进这个文件的同一条镜头里；镜头关键帧表（`KEYS`、`camFrom`）和顶部的时间点注释照这个写法。
  - `ending.tsx`：回到开场和最后一问。结构通用，换动作。
  - `Cover.tsx`：封面，横竖两种布局。
  - `Cast.tsx`：定妆图，只用来确认造型，不进成片。
  - `sfx.ts`：音效时间表。
- `src/ep01/sim.ts`、`scripts/tune.ts`：第一期的仿真和调参。只有算法型的期才需要，每期各写各的，不改别期的文件。

起一期新的：

1. 复制 `src/ep02` 为 `src/ep03`，把 `Ep02.tsx` 改名，组件名改成 `Ep03`。
2. 在 `src/Root.tsx` 里注册 `Ep03`、`Ep03Cover`、`Ep03Cast`。时长用本期 `script.ts` 的 `TOTAL_BARS`，各期的常量同名，导入时起别名。
3. 按选题表改 `script.ts`。
4. 在 `world.ts` 里画新角色，用 `Cast.tsx` 渲染定妆图，确认造型。
5. 重写世界那个文件：先做开场 6 秒并按第 11 节检查，再把症状、命名、机制、补丁排进同一条镜头。总装里删掉 `Symptoms`、`Title`、`Lab` 这几段和进度条、转场。
6. 改 `ending.tsx` 的相反动作。
7. 改 `sfx.ts`。`scripts/sfx.ts` 把所有音效写到 `public/sfx/`，各期共用：需要新声音时用新文件名添加，不改已有音效的合成参数，否则旧的一期重新渲染时声音会变。
8. 音乐由人在剪映里合；想在渲染时带上，就把文件放到 `public/` 下，文件名填进总装文件顶部的 `BGM`。
9. 改 `Cover.tsx`。

检查画面的办法：全片渲染一次要几分钟，改动期间用 `npx remotion still` 抽关键帧，用 ffmpeg 拼成一张图看。抽帧只能看构图，看不出节奏和是否好懂，完整的片子必须由人看一遍。

命令（把编号换成当期的）：

```bash
npm run studio
npx remotion render src/index.ts Ep02 out/ep02.mp4
npx remotion still src/index.ts Ep02Cover out/ep02-cover.png
npx remotion still src/index.ts Ep02 out/frame.png --frame=1800 --scale=0.33
npx tsx scripts/sfx.ts
npm run typecheck
```

## 10. 封面和发布文案

封面给结论：一句反常识的话加一个一眼能懂的画面。

- 标题两行，沿用同一句式和位置：「困住你的 / 是『更好』」「让你忘不掉的 / 是『别想』」。引号里的词按颜色规则上色，问题蓝，解法绿。
- 画面优先取自片中的揭示镜头。缩成小图看不清时单独画一张，只留一个主体（第二期：白熊自己举着「不许想」的牌子）。
- 底部小字放系列名、编号和概念名，左下角放小虫。
- 横屏视频只上传横版封面，所有内容放在中间 810 像素宽的范围内，主页网格只显示这一条。

发布文案三行，不另写长简介：

```
Vibe知识大赏 | 《白熊效应》

人生 bug 图鉴 EP 002

为什么越想忘掉的事，越是忘不掉？
```

第三行是把悖论改成的问句。它和封面那句是一问一答。

## 11. 制作顺序

1. 选概念，过第 2 节六关。准备两三个备选，一句话讲清困境、悖论、世界、补丁，再选。
2. 填选题表，查证出处。
3. 开工前先看第 13 节的数据。写纯文字分镜，逐段写画面和字，确认后再动手。重点确认前 6 秒、金句和后半段的情绪走向。
4. 把音乐的对点交给做音乐的人。
5. 算法型在这一步写仿真，拿到数字回填文案。
6. 画新角色，出定妆图确认。
7. 做画面，先做开场 6 秒。渲染出来，缩到手机竖屏信息流里的实际大小（横屏视频只占屏幕中间约三分之一高），和第一期的开场并排看，按第 5.1 节逐条核对，由人确认后再往下做：世界（含症状、命名、机制、补丁）→ 结尾。
8. 加音效，渲染全片，完整看一遍、听一遍。看不懂的段落回到第 5.4、5.13 节对照着改。
9. 出封面和发布文案。
10. 发布满 24 小时后，把数据记进第 13 节，再把这一期的新做法写回这份手册。
